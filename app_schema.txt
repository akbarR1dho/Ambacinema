nama aplikasi "ambacinema" -> jangan membuat folder baru dengan nama berikut

1. Tech Stack :
- Laravel 13 (frontend dan backend)
- Tailwind

2. Warna Utama tampilan UI : merah dan hitam yang menggambarkan suasana saat berada di dalam bioskop

3. Fitur:
- Autentikasi (login, logout, dan register)
- panel admin:
 - buat tampilan UI seperti tailadmin yang profesional, fungsional, dinamis berbagi perangkat dan modern
 - menggunakan datatable untuk table data -> style UI nya sesuaikan agar terlihat cantik 
 - CRUD daftar studio
 - CRUD daftar film
 - CRUD daftar jam tayang -> saat membuat jadwal jam tayang tidak boleh bentrok satu sama lain berdasarkan studio dan film, jika jam tayang di set melewati Waktu real timedalam rentang 1 jam (misal jam 8 maka sepanjang jam 8 tidak bisa, tetapi di jam berikutnya bisa) maka tidak bisa dibuat
 - Kursi auto generate ketika memasukkan jumlah kursi saat membuat studio
 - CRUD daftar pesanan

- panel user:
 - buat tampilan UI seperti website cinema 21
 - home (buatlah tampilan seperti website cinema 21)
 - pilih jam tayang (sesuaikan style nya seperti website cinema 21)
 - pilih kursi (buatlah tampilan kursi seperti pada website cinema 21)
 - konfirmasi pesanan -> setelah ter konfirmasi membuat qr code untuk memuat informasi film, user, dan kursi (sesuaikan style nya seperti website cinema 21)
 - daftar pesanan (buatlah tampilan seperti website cinema 21)
 - detail pesanan (buatlah tampilan seperti website cinema 21)
